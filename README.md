# 宝马车控 — REAREye背屏组件
为小米背屏制作的 BMW i3 车控卡片。卡片、图标、配套脚本与后台程序放在同一个组件包内。
# 功能

# 车辆信息
- 显示车型、时间、电量百分比和剩余电动续航。
- 按手机本地时间，在 **08:00—次日 01:00** 每个整点尝试读取车况。
- **02:00—07:59 暂停**背屏脚本的定时读取。
- 打开卡片显示缓存，不会为了显示页面立即查询云端车况。
- 查询失败时保留旧数据和原获取时间；操作提示约 4 秒后隐藏。

# 控车入口

| 按钮 | 行为 |
| --- | --- |
| 空调 | 使用官方已有授权，单次提交开启请求 |
| 闪灯 | 使用官方已有授权，单次提交闪灯请求 |
| 鸣笛 | 使用官方已有授权，单次提交鸣笛请求 |
| 锁车、解锁 | 转到前屏 My BMW，由官方流程操作 |
| 定位、打开 App | 打开前屏官方入口 |
| 更新授权 | 同步本机官方已有授权，不发送控车指令 |

界面不显示“直连／云端”标识。“已受理”表示请求被接收，最终执行以车辆或 My BMW 显示为准。超时、断网或未知结果不自动重发；HTTP 429 按限流处理。

# 使用条件

- 已安装并启用 REAREye，版本具备**组件自带脚本**和 **postinstall 安装后调用**功能。
- REAREye 已取得 Root，脚本接口可用。
- 已安装并登录中国大陆版 My BMW；此前适配版本为 6.9.0（54521）。
- 保留已有 Termux 和 Python，供后台任务使用。组件包内置脚本，不内置完整 Python 运行环境。
- 当前只处理已核对绑定的账号和车辆，不自动改绑到另一账号或另一辆车。

首次安装到尚未授权的手机时，仍可能需要确认 REAREye 的 Root 请求或在 My BMW 完成登录；系统权限不能用组件包预先授予。

# 安装与使用
# 云端下载

1. 在 REAREye 云端找到「BMW i3 车控」，下载并安装。
2. 宿主同时安装卡片与 `scripts/` 内的脚本，并通过安装后入口发起本机初始化。
3. 等待几秒，切换到 BMW 卡片。你已有的授权缓存、车辆绑定和负一屏组件会继续使用。
4. 若授权提示需要更新，在 My BMW 确认正常登录后，点击卡片「更多 → 更新授权」。
初始化只部署本机运行文件、准备定时器并同步官方已有授权；不会自动开空调、闪灯或鸣笛。曾手动暂停整点更新时，重新安装仍保留暂停状态。

**本地“导入模板”与云端安装不是同一个入口。** 单独把 ZIP 当模板导入，不能保证安装脚本或执行安装后初始化。不要在本地模板入口导入后就当作云端安装已完成。
# 安装异常

正常流程不需要手动填写 Provider。仅在排查时，进入 REAREye 的组件自带脚本项目 `component:bmw_i3_cloud`：

| Provider ID | 用途 |
| --- | --- |
| `bootstrap` | 重新发起本机初始化；有重复执行与失败冷却保护 |
| `bootstrap_status` | 查看本机初始化阶段 |
| `status` / `link` | 最近处理结果及脚本接收阶段 |
| `auth_info` | 查看缓存令牌的签发、到期和同步时间 |
| `runtime` / `schedule` | 查看运行库、定时器与最近车况阶段 |
| `updates_off` / `updates_on` | 暂停／恢复背屏整点车况查询 |

反馈提示文字或脱敏状态即可，不需要发送账号密码、Token 或官方 App 的完整数据文件。

# 授权与负一屏

官方 App／官方小组件负责更新授权，背屏脚本读取官方已有授权。访问令牌曾观察到约 **55 分钟**的声明有效期；同步缓存不会重新计算到期时间。本组件不提供独立手机号＋密码登录。

官方续航／车辆状态小组件曾帮助获取到新授权，但出现过约 12 分钟空档，不能保证无缝或永久续期。只显示遥控按钮的小组件不能等同于状态组件的后台更新。
没有可用的官方后台更新时，仍可通过 My BMW 正常登录／刷新后，在背屏同步授权。授权不可用或被接口拒绝时，既有控车流程请求打开前屏 My BMW，不自动补发刚才的指令。

# 文件结构

```text
manifest.xml             背屏布局和按钮
widget_info.json         云端安装元数据和初始化入口
icons/、strings/         图标和文字
scripts/main.lua         组件脚本与 Provider
scripts/lib/             本地辅助模块和初始化逻辑
scripts/worker.b64       控车与车况后台程序
scripts/scheduler.b64    整点车况调度器
scripts/launch.sh        后台任务启动器
scripts/boot.sh          已有 Root 环境的开机启动钩子
scripts/reader.b64       官方本机授权读取辅助程序
README.md、技术交接.md    使用与技术说明
```

# 通信流程

```text
云端安装 → REAREye 安装模板和脚本 → postinstall → 本机初始化
切换卡片 → 读取本机缓存
点击控车 → 组件脚本 → 后台核对账号、车辆与授权 → 单次请求
整点调度 → 云端车况读取 → 更新缓存 → 背屏显示
```
